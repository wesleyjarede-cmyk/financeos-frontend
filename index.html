Como funciona o Open Finance no Brasil
O Open Finance é regulado pelo Banco Central do Brasil e permite que você autorize, de forma segura, o compartilhamento dos seus dados bancários entre instituições participantes. Para integração em produção, é necessário contratar um agregador licenciado como Pluggy, Belvo ou Quanto, que já possuem autorização do BCB e APIs prontas para uso. Abaixo você pode configurar suas chaves de API e conectar seus bancos.
Configurar provedor de API
💡 Sem chave de API? Use o modo manual — importe extratos CSV/OFX diretamente dos apps dos bancos. Funciona com todos os bancos brasileiros.
